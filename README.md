# Solar-SketchUp



גרסה: 0.2.0
תאימות יעד: SketchUp Desktop 2021–2026 ב־Windows וב־macOS.

התקנה

פתח את SketchUp.

היכנס אל Window > Extension Manager.

לחץ Install Extension.

בחר את הקובץ Solar_Designer_IL_v0.2.0.rbz.

אשר את הודעת האבטחה. לאחר ההתקנה יופיע התוסף בתפריט Extensions ובסרגל כלים חדש.

יצירת פריסה

פתח את קובץ הפרויקט שלך.

אם הגג נמצא בתוך קבוצה, היכנס לעריכת הקבוצה בלחיצה כפולה.

בחר פאת גג אחת או כמה פאות מישוריות.

פתח Extensions > Solar Designer IL.

הזן את המידות וההספק לפי דף הנתונים של הפאנל המדויק.

בחר מצב הצבה:

צמוד לגג.

הטיה חד־כיוונית.

מזרח־מערב לסירוגין.

הגדר זווית מוחלטת מהאופק ואזימוט. הערכים משנים את הפאנלים עצמם בתלת־ממד.

אם הציר הירוק במודל אינו צפון, הזן את סטיית הצפון עם כיוון השעון.

הגדר מרווחים ונסיגה מהיקף.

לחץ בנה / עדכן פריסה.

קונבנציית האזימוט זהה ל־PVGIS: 0° = דרום, ‎−90° = מזרח, 90° = מערב ו־±180° = צפון. במצב מזרח־מערב התוסף יוצר כיוון בסיס וכיוון נגדי לסירוגין. במצב צמוד לגג שיפוע פאת הגג גובר על זווית היעד; במצב הטיה חד־כיוונית הזווית היא מוחלטת מהאופק ואינה תוספת לשיפוע הגג.

אפשר להפעיל מרווח שורות אוטומטי. במצב זה התוסף מחשב מרווח בקירוב לפי גובה הפאנל וזווית השמש המינימלית שהוגדרה.

כל הפעולות הגאומטריות ניתנות לביטול באמצעות Undo של SketchUp.

מכשולים ואזורים אסורים

בחר פאה, קבוצה או רכיב שמייצגים דוד, מזגן, מעקה או מעבר שירות.

לחץ סמן בחירה כאזור אסור.

בחר מחדש את פאת הגג.

בנה את הפריסה.

התוסף משתמש במעטפת המוקרנת של המכשול ומוסיף את מרחק הבטיחות שהוגדר.

מחרוזות ו־MPPT

בלשונית חשמל יש להזין את נתוני המודול והממיר. התוסף מחשב בקירוב:

מתח Voc בטמפרטורת האתר המינימלית.

מתח Vmp בטמפרטורת תא מרבית.

מספר פאנלים מינימלי ומקסימלי במחרוזת.

חלוקה מאוזנת למחרוזות ושיוך מחזורי ל־MPPT.

יחס DC/AC ואזהרות בסיסיות.

צבעי הפאנלים מייצגים מחרוזות שונות.

הצללה

הגדר מיקום, תאריך ושעה בחלון Shadows של SketchUp.

עבור ללשונית תפוקה והצללה.

לחץ נתח הצללה עכשיו.

אדום מציין שמרכז הפאנל מוצל ברגע שנבחר; ירוק מציין קו ראייה פתוח לשמש. זו בדיקת נקודת זמן ומרכז פאנל, ולא סימולציית הצללה שנתית מלאה.

PVGIS ודוח תפוקה שנתי

בנה או עדכן את הפריסה אחרי כל שינוי בזווית או באזימוט.

בלשונית תפוקה והצללה הזן קו רוחב, קו אורך והפסדי מערכת.

לחץ חשב והפק דוח תפוקה.

התוסף קורא את הזווית והאזימוט של הפאנלים בפועל, שולח חישוב נפרד לכל כיוון אל PVGIS ומחבר את התוצאות.

בחר מיקום לשמירת הדוח. הוא ייפתח אוטומטית בדפדפן.

בדפדפן לחץ הדפס / שמור כ־PDF ובחר Save as PDF / שמירה כ־PDF.

הדוח כולל תפוקה שנתית, תפוקה סגולית, תוצאות חודשיות, קרינה במישור, מיקום וקבוצות הזווית/אזימוט שנקראו מהמודל. אפשר גם ללחוץ חשב והצג בלבד, ולאחר מכן פתח דוח מהתוצאה האחרונה.

החישוב נשלח ישירות לשירות PVGIS 5.3 הרשמי. נדרש חיבור לאינטרנט.

ייצוא

בלשונית דוחות אפשר לייצא:

דוח HTML שניתן להדפיס ל־PDF.

CSV עם כל פאנל, מחרוזת ו־MPPT.

JSON מלא להמשך פיתוח או אינטגרציה.

גבולות הגרסה הנוכחית

מנוע המילוי מיועד לפאות מישוריות. אפשר לבחור כמה פאות של רשת, אך עדיין אין עטיפה רציפה על גג מעוקל כמו בגרסת Pro של Skelion.

בדיקת ההצללה היא בדיקת Ray Test לרגע נתון, לא חישוב שעות הצללה שנתי.

אין עדיין שרטוט חד־קווי, מסלול כבלים, חישוב חתכי מוליכים, הגנות או דוח קונסטרוקציה.

מידות ברירת המחדל הן נקודת פתיחה בלבד. חובה לאמת אותן מול דף הנתונים של דגם הפאנל המדויק.

אין להשתמש בתוצאה לביצוע או להגשה ללא בדיקה מקצועית מלאה ואישור הגורם המוסמך.

אבחון תקלה

אם מופיעה שגיאה פנימית, פתח Window > Ruby Console, חזור על הפעולה ושמור את הטקסט שמתחיל ב־[Solar Designer IL].
